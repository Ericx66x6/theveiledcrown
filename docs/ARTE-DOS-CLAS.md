# Arte dos clãs · 10.2

Quatorze ilustrações originais geradas para a seleção de linhagem, com direção visual urbana gótica/punk, preto, rubi e marfim. Não são artes oficiais de Vampire: The Masquerade. A geração foi realizada durante a produção dos arquivos; o site não integra IA nem faz chamadas de geração.

Os arquivos usados pelo aplicativo são WebP de **640 × 853 px**, com qualidade 82, aproximadamente 40–81 KB por retrato (864.644 bytes no conjunto). A composição mantém o rosto no terço superior para uso nas cartas e no destaque. Os PNGs de trabalho não integram o pacote.
